当前第一阶段后端包含：

- HTTP Basic 认证和 `/system/auth/me`；
- 用户创建、修改、启停、角色替换和分页详情；
- 角色创建、修改、权限替换和分页详情；
- 基础权限创建、修改和权限树；

- 生产批号加可选药品编码的只读追溯；
- 方法级权限编码；
- 操作日志、权限变更日志和业务状态历史写入；
- Knife4j、Swagger UI 和 OpenAPI JSON。

当前供应商状态：

```text

→ UNDER_REVIEW
→ APPROVED / REJECTED
```

`REJECTED` 可以修改后重新提交。提交会生成新审核轮次和资质快照；提交人不能审核本人；驳回原因必填。

## 5. 当前前端事实

### 5.1 工程与依赖

`frontend/` 当前包含：

- Vue 3.5.40；
- Vite 7.3.6；
- TypeScript 5.9.3；
- Element Plus 2.14.3；
- Vue Router 4.6.4；
- Axios 1.19.0；
- Vitest 4.1.10；
- Vue Test Utils 2.4.11；
- npm 锁文件；
- 开发代理、环境变量模板和 Nginx 反向代理示例。

`frontend/node_modules/` 和 `frontend/dist/` 被 `.gitignore` 排除。

### 5.2 已实现页面

| 页面 | 当前能力 |
| --- | --- |
| 登录 | HTTP Basic 身份验证；凭据只在运行内存保存；失败信息展示 |
| 工作台 | 当前用户、角色、权限数量和真实可访问模块 |
| 用户管理 | 查询、创建、修改、启停、替换角色 |
| 角色管理 | 查询、创建、修改、精确配置权限 |
| 基础权限 | 树形查询、显示停用项、创建根或子权限、修改节点 |
| 供应商列表 | 查询、筛选、创建草稿、进入办理 |
| 供应商详情 | 编辑档案、资质、附件元数据、完整性提示、提交、审核、历史轮次 |
| 批号追溯 | 批次档案、库存分布、生命周期时间线和事件证据快照 |
| 403 / 404 | 无权和不存在页面反馈 |

菜单、路由和按钮根据 `/system/auth/me` 返回的权限编码显示；后端仍是最终授权边界。

### 5.3 明确没有伪造的能力

- 没有后端部门目录接口，因此用户表单使用数字部门 ID；
- 没有文件上传接口，因此供应商页面只登记受控存储元数据；
- 没有审计查询接口，因此没有虚构审计日志页面；
- 没有统计接口，因此工作台只显示从当前用户计算出的数量；
- 没有追溯数据时显示真实空结果，不生成模拟业务节点；
- 没有两级供应商审批接口，因此页面不显示未实现的质量管理员初审节点。
