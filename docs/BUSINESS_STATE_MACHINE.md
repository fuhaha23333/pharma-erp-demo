# 药品批发 ERP Demo 业务状态机说明（BUSINESS_STATE_MACHINE）

> 文档版本：v1.0
> 文档状态：冻结基线
> 上位范围文件：docs/DEMO_SCOPE.md v1.1
> 上位业务流程：docs/BUSINESS_FLOW.md v1.0

## 1. 文档目的

本文档定义 Demo 中业务对象的：

- 状态；
- 状态转换；
- 触发动作；
- 执行角色；
- 前置条件；
- 阻断规则；
- 审计要求。

本文档不冻结：

- 数据库字段；
- Java枚举值；
- API地址；
- 页面设计；
- 工作流引擎。

药品批次追踪、序列化和供应链事件记录是药品系统的重要能力，因此状态变化必须保持完整事件链。

---

# 2. 通用状态转换规则

所有状态变化必须记录：

- 操作人；
- 操作时间；
- 原状态；
- 新状态；
- 操作原因；
- 关联业务记录；
- 审批信息（如需要）。

禁止：

- 直接修改状态绕过流程；
- 删除历史状态变化；
- 绕过质量控制步骤。

# 3. M1 全国核心状态机

## SM-01 药品档案状态

### 状态

```text
草稿
→ 待完善
→ 可提交首营
→ 停用
```

### 转换规则

  当前状态     动作           下一状态     角色

---

  草稿         保存资料       待完善       资料维护人员
  待完善       完成资料检查   可提交首营   资料维护人员
  可提交首营   停用           停用         授权人员

规则：

- 药品档案不能直接进入采购；
- 停用药品不能销售。

---

## SM-02 首营企业状态

### 状态

```text
草稿
→ 待质量审核
→ 待质量负责人批准
→ 已批准
```

异常：

```text
待质量审核
→ 退回补充

待质量负责人批准
→ 驳回
```

### 转换规则

  当前状态           动作       下一状态           角色

---

  草稿               提交审核   待质量审核         采购员
  待质量审核         审核通过   待质量负责人批准   质量管理员
  待质量负责人批准   批准       已批准             质量负责人
  待质量审核         退回       草稿               质量管理员

规则：

- 未批准不能采购；
- 质量管理员不能代替质量负责人最终批准。

---

## SM-03 首营品种状态

状态：

```text
草稿
→ 待质量审核
→ 待质量负责人批准
→ 已批准
```

规则：

- 未批准品种不能采购；
- 药品资料重大变化可能触发重新审核。

---

## SM-04 客户资质状态

状态：

```text
草稿
→ 待审核
→ 有效
```

异常：

```text
待审核
→ 退回

有效
→ 冻结

有效
→ 失效
```

规则：

- 无效、冻结客户不能销售；
- 销售前必须动态校验。

---

# 4. 采购与库存状态机

## SM-05 采购订单状态

状态：

```text
草稿
→ 已确认
→ 部分收货
→ 完成
```

异常：

```text
草稿
→ 关闭

已确认
→ 关闭
```

规则：

- 采购订单不能直接形成库存；
- 已产生收货记录后不得直接关闭。

---

## SM-06 收货状态

状态：

```text
待收货
→ 已收货
→ 待验
```

规则：

- 收货不等于验收；
- 收货人员不能作最终质量判断。

---

## SM-07 验收状态

状态：

```text
待验收
→ 验收中
→ 合格
```

异常：

```text
验收中
→ 不合格
```

规则：

- 必须逐批验收；
- 合格后才能形成可销售库存；
- 不合格不得进入销售库存。

---

## SM-08 批号库存质量结论

状态：

```text
待验
→ 合格
```

质量转换：

```text
合格
→ 冻结

冻结
→ 合格

冻结
→ 不合格

合格
→ 过期
```

规则：

- 待验不能销售；
- 冻结不能销售；
- 不合格不能销售；
- 过期不能恢复为合格可销售状态。

---

## SM-09 库存占用状态

状态：

```text
可用
→ 已占用
→ 已出库
```

异常：

```text
已占用
→ 已释放
```

规则：

- 占用不能超过可用数量；
- 出库失败必须释放占用。

---

# 5. 销售与出库状态机

## SM-10 销售订单状态

状态：

```text
草稿
→ 待客户校验
→ 已确认
→ 待分配批次
→ 已分配批次
→ 待出库复核
→ 完成
```

异常：

```text
待客户校验
→ 驳回

草稿/已确认
→ 关闭
```

规则：

- 客户资质通过后才能确认；
- 必须关联合格批次。

---

## SM-11 出库复核状态

状态：

```text
待复核
→ 复核通过
→ 已出库
```

异常：

```text
待复核
→ 复核不通过
```

规则：

- 复核失败不能发运；
- 未复核通过不能扣减最终库存。

---

## SM-12 发运与签收状态

M1：

```text
待发运
→ 已发运
→ 已签收
```

M2增强：

```text
已发运
→ 运输异常
```

规则：

- 未完成出库不能发运；
- 签收信息进入追溯链。

---

# 6. M2 广东增强与质量状态机

## SM-13 质量事件状态

状态：

```text
已创建
→ 调查中
→ 待审批
→ 已处置
→ 关闭
```

规则：

- 质量管理员负责调查；
- 质量负责人审批重大处置。

质量事件状态独立于库存冻结状态。

---

## SM-14 库存冻结与质量处置状态

状态：

```text
正常
→ 冻结
```

转换：

```text
冻结
→ 解除冻结

冻结
→ 不合格
```

规则：

- 冻结期间禁止销售和出库；
- 必须有原因和审批记录。

---

## SM-15 广东追溯码本地核验状态

> 状态边界说明：
>
> - SM-15 负责广东追溯码本地采集、核验和业务关联；
> - SM-16 负责 Mock 外部交换过程，包括请求、处理中、成功、失败和重试；
> - 本地核验成功不等于 Mock 上传成功，两个状态机必须独立记录。

状态：

```text
待核验
→ 核验通过
→ 待上传
→ 上传中
→ 上传成功
```

异常：

```text
待核验
→ 核验失败

上传中
→ 上传失败
```

规则：

- 重复码阻断；
- 药品、批号、数量不一致阻断；
- Mock失败不能伪装成功。

# 7. M3 演示加固状态机

## SM-16 广东追溯码 Mock交换状态

状态：

```text
待上传
→ 上传中
→ 上传成功
```

异常：

```text
上传中
→ 上传失败
```

规则：

- Mock失败不能伪装成功；
- 上传记录必须保留请求、结果和失败原因；
- Mock成功不代表真实监管平台接收成功。

# 8. 禁止状态跳转

禁止：

```text
采购订单 → 库存
```

原因：

采购不是库存来源。

禁止：

```text
待验 → 合格库存
```

原因：

缺少验收合格记录。

禁止：

```text
冻结 → 销售完成
```

原因：

冻结库存不可销售。

禁止：

```text
复核失败 → 已出库
```

原因：

未完成出库控制。

禁止：

```text
未批准首营 → 采购
```

原因：

未完成准入。

禁止：

```text
资质失效客户 → 销售完成
```

原因：

客户准入失败。
